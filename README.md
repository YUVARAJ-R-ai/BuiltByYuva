# Yuvaraj R — Professional Developer Portfolio

A premium, interactive developer portfolio built for **Yuvaraj R** — ML Engineer, Agentic Systems Builder, and Linux Native. 

The aesthetic is designed at the intersection of a high-end SaaS product (think Vercel) and a perfectly riced Hyprland desktop environment. It emphasizes a technical personality with restraint and craftsmanship.

## Features

- **Interactive Hero Terminal**: A custom-built, fully functional macOS/Kitty style terminal. Try running `whoami`, `skills`, `projects`, or even `sudo`.
- **Hyprland-inspired Grid Tiling**: The Projects section utilizes a master-stack layout to showcase featured and secondary work.
- **Premium Aesthetics**: Built with a strict palette (Deep background with cool cyan and muted violet accents).
- **Zero-Bloat UI**: Powered by React and heavily customized Vanilla CSS, keeping animations snappy and styles explicit.
- **Responsive Design**: Adapts gracefully to all screen sizes.

## Technical Stack
- **Framework**: React + Vite
- **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid, custom micro-interactions)
- **Typography**: Inter (Headings) & JetBrains Mono (Code, metadata, tags)

## Run Locally

**Prerequisites:** Node.js

1. Clone the repository:
   ```bash
   git clone https://github.com/YUVARAJ-R-ai/Yuvaraj_professional_porfolio.git
   cd Yuvaraj_professional_porfolio
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Design Philosophy

- **Professional is the frame. Personality is the signal inside it.**
- Generous whitespace driven by a 12-column grid.
- Strict typography rules: No mixing beyond Inter and JetBrains Mono.
- Subtle micro-interactions over theatrical animations.
